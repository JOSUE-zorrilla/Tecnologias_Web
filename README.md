# Mz Distribuciones

Sitio web estático hecho con HTML5 y CSS para la Actividad Práctica 1 de Tecnologías Web.

Tema: **Impacto de las Tecnologías Web en la Sociedad y los Negocios**.

## Páginas

- `index.html`: inicio
- `pages/nosotros.html`: historia de la empresa
- `pages/impacto.html`: impacto de las tecnologías web (tabla y video)
- `pages/servicios.html`: servicios y productos
- `pages/contacto.html`: formulario de contacto

## Cómo verlo

Abrir `index.html` en el navegador. El video de YouTube solo carga si el sitio se abre desde un servidor (GitHub Pages o Live Server en VS Code), no con doble clic.

Las fotografías son de Wikimedia Commons; los créditos están en la página de servicios.

Sitio publicado: https://josue-zorrilla.github.io/Tecnologias_Web/
